# Спецификация: просмотр поста

## Цель
Открывать отдельный экран публикации по нажатию на карточку в списке.

## Стек и ограничения
- Expo + TypeScript, `fetch`, `useEffect`, `useState`.
- Загружать выбранный пост отдельным запросом `GET /api/v1/posts/{id}` через `getPost` из `api.ts`.
- ID передавать типизированным параметром навигации.

## Критерии готовности
- [ ] Нажатие на карточку открывает экран соответствующего поста.
- [ ] Экран загружает пост по ID с сервера.
- [ ] Во время загрузки показан индикатор; при ошибке/404 — сообщение.
- [ ] Экран показывает заголовок, полный текст и дату.
- [ ] Можно вернуться к списку постов.

## Что не делаем
- Не используем данные из карточки вместо запроса отдельного поста.
- Не создаём, не редактируем и не удаляем посты; никаких POST/PUT/DELETE.
