# Спецификация: Welcome и вкладки

## Цель
Создать приветственный экран учебного мобильного приложения и навигацию между разделами курса.

## Стек и ограничения
- Expo + React Native + TypeScript.
- Экраны Welcome, Labs и About вынесены в отдельные компоненты в `screens/`.
- Для навигации используются нижние вкладки React Navigation и отдельный стек лабораторных экранов.
- Интерфейс собран из стандартных компонентов React Native и `StyleSheet`.
- Welcome использует кнопку «Начать» и controlled-поле имени.

## Критерии готовности
- [ ] При запуске открывается вкладка «Главная».
- [ ] На Welcome видны приветствие, поле имени и кнопка «Начать».
- [ ] Кнопка меняет состояние и показывает подтверждение.
- [ ] Вкладки «Главная», «Лабы» и «О проекте» переключаются.
- [ ] Из «Лаб» открываются экраны счётчика, таймера и постов.
- [ ] Экраны вынесены в отдельные файлы в `screens/`.
- [ ] Приложение собирается для запуска в Expo Go.

## Что не делаем
- Не добавляем сложную навигацию, UI-kit, серверную логику приветствия или анимации.
- Не сохраняем имя и состояние кнопки после закрытия приложения.
