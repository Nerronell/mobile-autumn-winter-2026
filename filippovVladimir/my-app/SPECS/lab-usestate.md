# Спецификация: useState-счётчик

## Цель

Создать учебный экран-счётчик, чтобы попрактиковаться в хранении и обновлении состояния с помощью React-хука `useState`.

## Стек и ограничения

- Expo + React Native + TypeScript.
- Счётчик расположен на вкладке «Лабы» или отдельной вкладке «Счётчик».
- Интерфейс состоит из текущего значения и кнопок «+», «−» и «Сбросить».
- Для состояния и стилей использовать `useState` и `StyleSheet`; сторонние библиотеки не добавлять.
- Начальное значение — `0`; значение не может быть меньше `0`.

## Критерии готовности

- [ ] На экране отображается текущее значение счётчика.
- [ ] Кнопка «+» увеличивает значение на `1`.
- [ ] Кнопка «−» уменьшает значение на `1`, но не ниже `0`.
- [ ] Кнопка «Сбросить» возвращает значение к `0`.
- [ ] Значение обновляется на экране после нажатия.
- [ ] Код счётчика и обновления состояния можно объяснить на защите.

## Что не делаем

- Не сохраняем счётчик в AsyncStorage или на сервере.
- Не добавляем анимации, настраиваемый шаг или сложные ограничения.
