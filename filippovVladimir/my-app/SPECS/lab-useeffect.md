# Спецификация: таймер useEffect

## Цель
Познакомиться с побочным эффектом React на примере секундного таймера, работающего пока открыт экран.

## Стек и ограничения
- Expo + React Native + TypeScript.
- Отдельный экран доступен через вкладку «Лабы».
- Хранить секунды в `useState`, запускать интервал в `useEffect` с пустым массивом зависимостей.
- Очищать интервал при уходе с экрана.

## Критерии готовности
- [ ] При открытии таймера отображается `0`.
- [ ] Значение увеличивается раз в секунду.
- [ ] При уходе с экрана интервал очищается.
- [ ] Экран доступен из навигации «Лабы».

## Что не делаем
- Не сохраняем время и не запускаем таймер в фоне.
- Не используем сервер или сторонние библиотеки.
