# Спецификация: controlled TextInput

## Цель
Научиться управлять полем ввода через состояние React и показывать введённое имя в приветствии.

## Стек и ограничения
- Expo + React Native + TypeScript.
- Поле находится на экране Welcome.
- Значение поля хранится в `useState`.
- Использовать controlled `TextInput`: `value` из state и `onChangeText` для обновления state.

## Критерии готовности
- [ ] Можно ввести имя в поле.
- [ ] Приветствие обновляется сразу при вводе.
- [ ] Для пустого или состоящего из пробелов имени показывается «Добро пожаловать!».
- [ ] Поле корректно отображается на экране телефона с открытой клавиатурой.

## Что не делаем
- Не отправляем имя на сервер и не сохраняем после закрытия приложения.
- Не добавляем валидацию email, маски ввода или библиотеки форм.
