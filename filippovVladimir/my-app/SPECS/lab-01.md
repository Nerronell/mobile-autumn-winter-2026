# Лабораторная работа 01: useState-счётчик

## Цель

Создать один экран-счётчик, чтобы на практике освоить React state: хранить число в `useState` и обновлять интерфейс при нажатии на кнопки.

## Стек и ограничения

- React Native + Expo + TypeScript.
- Один функциональный компонент экрана.
- Для состояния счётчика использовать React-хук `useState`.
- Интерфейс собрать из встроенных компонентов React Native.
- Значение при первом открытии экрана — `0`.
- Изменять значение только кнопками на экране; счётчик может принимать отрицательные значения.
- Сторонние библиотеки и дополнительные хранилища состояния не использовать.

## Критерии готовности

- [ ] При открытии экрана отображается значение `0`.
- [ ] На экране есть кнопки увеличения, уменьшения и сброса счётчика.
- [ ] Нажатие «+» увеличивает значение ровно на `1`.
- [ ] Нажатие «−» уменьшает значение ровно на `1`; отрицательные значения допустимы.
- [ ] Нажатие «Сбросить» устанавливает значение `0`.
- [ ] Новое значение отображается сразу после каждого нажатия.
- [ ] Экран запускается в Expo и остаётся читаемым на экране телефона.

## Что не делаем

- Не сохраняем значение после перезапуска приложения.
- Не добавляем навигацию, дополнительные экраны или серверную часть.
- Не используем сторонние библиотеки, глобальное состояние или сложные архитектурные решения.
- Не добавляем историю изменений, настраиваемый шаг, ограничения диапазона или анимации.
