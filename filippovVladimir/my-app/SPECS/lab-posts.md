# Спецификация: список постов

## Цель
Получать и показывать список публикаций учебного сервера на мобильном экране.

## Стек и ограничения
- Expo + TypeScript, `fetch`, `useEffect`, `useState`, `FlatList`.
- Источник: только `GET http://185.233.185.109:8080/api/v1/posts` через `getPosts` из `api.ts`.
- Карточка показывает заголовок, текст и дату.

## Критерии готовности
- [ ] Список загружается при открытии экрана.
- [ ] Во время загрузки отображается индикатор.
- [ ] Ошибка отображается понятным текстом и позволяет повторить запрос.
- [ ] Пустой список показывает сообщение «Постов пока нет».
- [ ] Для отображения используется `FlatList` с ключом по ID.
- [ ] Экран доступен во вкладке «Лабы».

## Что не делаем
- Не создаём, не редактируем и не удаляем посты.
- Не добавляем авторизацию, axios или библиотеки управления запросами.
