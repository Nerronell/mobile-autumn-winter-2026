# Lab: useState (счётчик)

## Цель
Учебный экран-счётчик на `useState`.

## Стек
Expo + TypeScript, отдельная вкладка **Labs**.

## UI
- Число по центру экрана
- Кнопки: **+**, **−**, **Reset**

## Поведение
- Старт: `0`
- `−` не опускает значение ниже `0`
- `Reset` → возвращает к `0`

## Ограничения
- Только `useState` + `StyleSheet`
- Без сторонних библиотек

## Готово, если
- [ ] Три кнопки работают
- [ ] Экран доступен из табов
- [ ] Код объясним на защите

## Не делаем
- AsyncStorage
- Сервер
- Анимации
