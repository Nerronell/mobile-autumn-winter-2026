# Lab: useEffect (имитация загрузки)

## Цель
Учебный экран с `useEffect`: имитация загрузки данных и отображение списка.

## Стек
Expo + TypeScript, отдельная вкладка **Effects** (или **Loading**).

## UI
- Индикатор загрузки (`ActivityIndicator`) — 1.5 секунды
- Потом список из 3 фейковых пунктов:
  1. Первый элемент
  2. Второй элемент
  3. Третий элемент
- Кнопка «Перезагрузить» — снова показывает загрузку

## Поведение
- Старт: `loading = true`
- `useEffect` с `setTimeout` 1500 мс → `loading = false`, заполняет массив
- Кнопка «Перезагрузить» → очищает список, `loading = true`, снова таймер
- При размонтировании — очистка таймера (`clearTimeout`)

## Ограничения
- Только `useState` + `useEffect` + `StyleSheet`
- Без реального API, без fetch
- Без сторонних библиотек

## Готово, если
- [ ] Спиннер видно 1.5 сек
- [ ] Появляется 3 пункта
- [ ] Кнопка «Перезагрузить» повторяет сценарий
- [ ] В `useEffect` есть cleanup (clearTimeout)

## Не делаем
- Реальный fetch
- AsyncStorage
- Анимации появления
